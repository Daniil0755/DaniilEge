# Задача 21742 (ЕГЭ №10)

(А. Ходарин)  В терминологии сетей TCP/IP маской сети называют двоичное число, которое показывает, какая часть IP-адреса узла сети относится к адресу сети, а какая – к адресу узла в этой сети. Адрес сети получается в результате применения поразрядной конъюнкции к заданному адресу узла и маске сети. Сеть задана IP-адресом одного из входящих в неё узлов 95.24.20.25 и маской сети 255.255.252.0. Сколько ещё устройств можно подключить к этой сети, если известно, что к сети кроде данного узла подключено 3 ноутбука, 4 мобильных телефона, 2 планшета и smart-горшок с кактусом? В ответе укажите только число.
